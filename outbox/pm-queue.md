# Project Manager source queue

This is a pull-only queue for public sources discovered during threat-model
work that are not already recorded by an owning Beryllium research component.
The threat-modeler appends `new` rows. The Project Manager owns later status
transitions.

| Discovery ID | Package | Source | Stable public locator | Suggested owner | Status | Reason |
| --- | --- | --- | --- | --- | --- | --- |
| None | None | No queued source. | None | None | None | Append new rows; do not remove history. |
